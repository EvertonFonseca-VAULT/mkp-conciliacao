Como rodar: Koncili → Para Processar

Guia de entendimento e execução da frente que vem antes da conciliação com o extrato bancário: baixar o AB no Koncili, conferir se bate, e gerar o arquivo que entra no TOTVS. Código completo já está nesta mesma pasta (RODAR CANAL), com LEIA-ME.txt, criar_pastas.bat e rodar_testes.bat.

2 etapas 8 canais precisa de credencial

O mecanismo, em 1 figura

O Koncili é a fonte: ele já fechou o repasse do dia. O resto do processo só confere isso e traduz pro formato que o TOTVS entende.

Checklist de preparo

Marque conforme for resolvendo — a barra no topo acompanha.

1. Instalar

Abrir PowerShell dentro desta pasta (RODAR CANAL) e rodar, nesta ordem:

PowerShell
python -m pip install -r requirements.txt
PowerShell
python -m playwright install chromium

O chromium só é usado pelo passo 5 (KONCILI), pra logar e baixar o AB. O Para Processar (passo 6) não usa navegador.

Sempre python -m ... (nunca pip/playwright soltos) — evita "comando não reconhecido" quando o Scripts\ do Python não está no PATH.

2. Pastas e acessos

Rodar uma vez, dando duplo clique:

nesta pasta
criar_pastas.bat

Isso cria as pastas locais em C:. Faltam 3 coisas que ninguém cria por script:

Unidade X: mapeada

É onde mora o AB (entrada) e o Para Processar precisa ler de lá. Pedir caminho/acesso ao Everton ou à TI.

TOTVS_2022.xlsx

Vai em C:\KIT CONCILIACAO MKP\TOTVS_2022.xlsx. É o export do TOTVS que o cruzamento usa pra achar cada pedido — sem ele, o passo 6 quebra na hora. Pedir ao Everton.

PTI do dia

CSV que vai em C:\TEMP\, um por canal (ELETRO não usa). Precisa colocar o do dia antes de rodar o Para Processar daquele canal:

CanalArquivo esperado em C:\TEMP\
FULLPTI FULL*.csv
ESPTI ES.csv
MOVEISPTI MOVEIS.csv
ELETRO(não usa)
CENTERPTI CENTER.csv
CO05PTI COLETAS 05.csv
PRIMEPTI_PRIME.csv
WEBPTI WEB.csv
Sem X: mapeado, sem o TOTVS_2022.xlsx ou sem o PTI do dia: dá erro (FileNotFoundError). No modo TODOS, só pula o canal que faltou e segue com os outros.

3. Cofre de senha — login do Koncili

O login/senha do Koncili nunca fica no código — ele vem só de 2 variáveis de ambiente que o koncili.py lê na hora de rodar. Se faltar alguma, o script para sozinho e avisa qual.

Opção A — só pra esta sessão do PowerShell

Mais simples, mas some se fechar o terminal (precisa rodar de novo na próxima vez).

PowerShell
$env:KONCILI_USUARIO="seu_email@webcontinental.com.br"
$env:KONCILI_SENHA="sua_senha"

Opção B — permanente (recomendado)

Grava na sua conta do Windows. Rodar 1 vez; depois disso, fechar e abrir o PowerShell de novo pra valer.

PowerShell
[Environment]::SetEnvironmentVariable("KONCILI_USUARIO","seu_email@webcontinental.com.br","User")
[Environment]::SetEnvironmentVariable("KONCILI_SENHA","sua_senha","User")
obrigatória KONCILI_USUARIO
obrigatória KONCILI_SENHA

Opcional — só se for usar o fallback do SRI

O Para Processar tem um 2º caminho pra achar um pedido que o TOTVS não encontrou: pesquisa direto no SRI. O código do scraper (pasta Screaper Mercado) já vem junto nesta pasta — só falta a credencial. Sem ela, o processo funciona normal — só fica sem esse fallback e deixa o pedido em VERIFICAR.

opcional SRI_USUARIO
opcional SRI_SENHA
Nunca cole usuário/senha dentro de um arquivo .py/.bat nem mande por chat/print. Qualquer um com acesso a essa pasta no X: veria.

4. Testar a instalação

100% offline — não toca o X:, o C:\RODAR TOTVS nem faz login no Koncili. Só confirma que Python + bibliotecas estão certos, antes de rodar com dado real.

nesta pasta
rodar_testes.bat

Roda, em sequência: koncili.py --teste, koncili_shopee.py --teste, rodar_canal.py --teste, ES\rodar_es.py --teste, FULL\escolher_full.py --self-test, ES\escolher_es.py --self-test.

Cada um imprime arquivo: ok no final. Se algum falhar, o problema é instalação (venv errado, lib faltando) — ainda sem risco de mexer em dado real.

5

Baixar o AB e conferir o valor

Entra na pasta KONCILI e roda com o canal + a data. Isso não grava nada ainda — só confere.

PowerShell
cd KONCILI
python koncili.py ES 22.09.2026

Quando bater, grave no X: com --salvar (não sobrescreve um AB que já exista):

PowerShell
python koncili.py ES 22.09.2026 --salvar

Vários dias de uma vez:

PowerShell
python koncili.py ES 11.09.2026 20.09.2026 --intervalo --salvar

Como ler a resposta

O script imprime uma linha por dia, por exemplo:

ES 22.09.2026: repasse 48213 | AB 48.211,07 | Koncili 48.211,07 OK | calendario 48.211,07 OK

OK nos dois = pode seguir pro passo 6. DIFERE = parar e investigar antes (ver aba Cuidados).

6

Gerar o Para Processar

Cruza o AB com o TOTVS/SRI e grava o arquivo que o processo automático do TOTVS importa. Voltar pra raiz da pasta antes de rodar.

PowerShell
cd ..\PARA_PROCESSAR
python rodar_canal.py ES 22.09.2026

Outros usos

todos os canais, 1 dia
python rodar_canal.py TODOS 22.09.2026
vários dias (listar 1 a 1, não é intervalo)
python rodar_canal.py FULL 11.09.2026 18.09.2026
sobrescrever um que já existe
python rodar_canal.py ELETRO 11.09.2026 --forcar
testar com um AB de mentira, sem tocar no real
python rodar_canal.py WEB 22.09.2026 --ab "X:\caminho\MERCADO WEB_teste 22.09.2026.xlsx"

O que o terminal mostra

ES 22.09.2026: 184 linhas | H:M 48.211,07 | Verificar 3 de 184 pedidos -> C:\RODAR TOTVS\...\PROCESSAR_MERCADO COLETAS ES 22.09.xlsx

"H:M" tem que bater com o valor do passo 5. "Verificar" são pedidos que não acharam par automático no TOTVS/SRI — normal ter alguns, acompanhado à parte.

7. Cuidados

  • VPN caída derruba o acesso ao X: — trava o passo 5 inteiro (e o 6, que lê o AB de lá).
  • DIFERE contra o calendário no passo 5: às vezes o calendário é que está errado (já aconteceu, ex. MOVEIS 04/09) — nesse caso o AB × Koncili (as 2 primeiras colunas da linha impressa) é que vale. Confirmar com o Everton antes de achar que o processo falhou.
  • Não mover nem renomear as pastas COMUM\, KONCILI\, PARA_PROCESSAR\ (nem ES\/FULL\/MOVEIS\ dentro dela) — o código importa de uma pasta pra outra pelo nome exato.
  • Arquivo final estranho (valor ou nº de linhas muito diferente do esperado): rodar o passo 5 (Koncili) de novo pra esse dia antes de desconfiar do passo 6 — não confiar só no H:M bater sozinho, conferir se o AB usado é o certo.
  • Credenciais nunca em arquivo versionado nem em print/chat (ver aba 3).
  • FileNotFoundError no passo 6 quase sempre é: X: não mapeado, TOTVS_2022.xlsx ausente, ou PTI do dia faltando em C:\TEMP\.

Dúvida que não está aqui: LEIA-ME.txt nesta mesma pasta tem o passo a passo completo em texto, e o Everton é o dono do processo.
